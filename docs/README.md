# Documentação — Portal Associativo

Documentação interna do projeto. Para o estado **atual** da arquitetura multi-tenant (não o histórico fase a fase), ver **[`CLAUDE.md`](../CLAUDE.md)** na raiz deste repositório — é a fonte de verdade viva, mais atualizada que as pastas abaixo.

| Pasta | Conteúdo |
|---|---|
| [architecture/](architecture/) | Decisões técnicas e arquiteturais do projeto — inclui `PERMISSIONS.md` (matriz de permissões dos dois planos de identidade) |
| [glossary/](glossary/) | Glossário de termos da plataforma (tenant, organização, papéis, Tenant Resolver, White Label, Feature Flags) |
| [roadmap/](roadmap/) | Histórico completo por fase (site institucional + plataforma SaaS), com relatório dedicado para cada fase relevante |
| [brand-system/](brand-system/) | Identidade visual: logo, cores, tipografia, tom de voz |
| [design-system/](design-system/) | Tokens, componentes e padrões de UI reutilizáveis |
| [ux/](ux/) | Fluxos de usuário, personas, jornadas |
| [ui/](ui/) | Wireframes, telas, especificações visuais |
| [marketing/](marketing/) | Posicionamento, segmentos, planos e precificação |
| [seo/](seo/) | Estratégia de SEO, palavras-chave, metadados |
| [copywriting/](copywriting/) | Textos definitivos do site (títulos, CTAs, FAQ) |

`brand-system/`, `roadmap/` e `architecture/` têm conteúdo substancial hoje; `ux/`, `ui/`, `marketing/`, `seo/`, `copywriting/` têm conteúdo real mas parcial — cada pasta declara no próprio `README.md` o que já está pronto e o que falta.
