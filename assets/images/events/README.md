# assets/images/events/

Reservado para fotografia de eventos reais de associações-clientes (ver
Creative Direction §4.6 — "fotografia documental... como se fosse tirada
por alguém presente no evento"). Nenhuma seção da Landing atual precisa de
foto de evento — `pages/funcionalidades.html#eventos` descreve o módulo por
texto/ícone, e a Home não tem seção dedicada a eventos. Pasta vazia por
enquanto, não removida, para já existir o lugar certo quando houver fotos
reais de eventos de associações-clientes para publicar.
