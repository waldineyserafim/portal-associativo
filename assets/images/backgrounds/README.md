# assets/images/backgrounds/

Reservado para texturas/fundos fotográficos de apoio (ex.: um fundo
fotográfico sutil atrás do CTA final, hoje resolvido só com cor sólida
`var(--brand-dark)`). Nenhuma seção desta rodada precisou de imagem de
fundo além do Hero (que vive em `assets/images/hero/`, por ser o elemento
dominante da própria seção, não um "fundo" secundário). Pasta vazia por
enquanto.
