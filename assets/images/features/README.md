# assets/images/features/

Reservado para fotografia de apoio à seção Funcionalidades, caso uma
revisão futura decida que algum módulo se beneficia de imagem além do
ícone. Decisão desta rodada de Art Direction: a seção "O que muda no seu
dia a dia" na Home usa uma lista calma ícone+texto (Creative Direction
§12.2 — "apresentar com calma, um de cada vez, nunca uma grade densa"), sem
fotografia — os ícones já cumprem a função sem competir com as fotos de
Segmentos/Hero pela atenção do visitante. Pasta vazia por enquanto.
